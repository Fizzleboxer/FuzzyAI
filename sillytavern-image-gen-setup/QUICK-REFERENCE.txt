TROUBLESHOOTING QUICK FIXES
============================

Connection Failed:
✓ Is Forge running? (START-SD-FORGE.bat)
✓ See "Running on local URL: http://127.0.0.1:7860"?
✓ Try opening http://127.0.0.1:7860 in browser

Too Slow:
✓ Use SD 1.5 models instead of SDXL
✓ Reduce resolution to 512x512
✓ Reduce steps to 20
✓ Close other GPU apps

Out of Memory:
✓ Close browser/games
✓ Reduce resolution
✓ Use SD 1.5 models
✓ Check --medvram is in launch args

Low Quality:
✓ Increase steps to 30-40
✓ Try DPM++ 2M Karras sampler
✓ Improve prompt details
✓ Add quality tags: "masterpiece, best quality"
