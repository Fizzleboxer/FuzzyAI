INSTALLATION INSTRUCTIONS
==========================

1. Download your chosen model (.safetensors file)

2. Place it in this folder:
   C:\SD-Forge\stable-diffusion-webui-forge\models\Stable-diffusion\

3. Restart Forge (close and run START-SD-FORGE.bat again)

4. Select the model in the WebUI dropdown at the top left

5. Or select it in SillyTavern's Image Generation settings

✓ Describe lighting, mood, composition
✓ Specify art style if desired

EXAMPLE:
"masterpiece, best quality, 1girl, long red hair, green eyes,
wearing elegant dress, sitting on beach, sunset, warm lighting,
detailed face, photorealistic"

NEGATIVE PROMPTS (what to avoid):
"low quality, worst quality, bad anatomy, bad hands, missing fingers,
extra digits, fewer digits, text, watermark, signature, username,
blurry, ugly, disfigured"
